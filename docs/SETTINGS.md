# Settings and menu appearance

Aerie's resizable Settings window has a left sidebar and scrolling native forms. Changes stay in a draft until **Apply**; **Close** discards unapplied edits. Imported profiles and Restore Defaults are reviewed before staging. Forms stay at a readable width on large displays, and Zoom opens a bounded enlarged frame. At manual launch, Settings waits for the first normal sample to fill its interface and sensor inventories, with a two-second fallback if sampling is delayed.

- **General:** collection interval, full or on-demand sensor sampling, process grouping/sorting, units, theme, numeric history and configuration transfer.
- **Menu Bar:** a native preview reports Aerie’s width in points. **Use Compact Layout** stages upright letters stacked top to bottom, 15-point native condensed primary readings, an icon-only application control and zero inside padding/grouped gaps while preserving module visibility, order, sampling and sources. Fresh configurations use it; saved custom configurations remain intact. NET keeps its existing 8.5-point numbers and 8-point units on two rows; its type is not enlarged. Compact numeric modules have fixed widths, missing values use a dash, and oversized values use an explicit overflow mark with full details in tooltips and accessibility. Compact network columns preserve byte/bit distinction with shorter bit units. Grouped modules, separate items or the existing combined dashboard; visibility/order/style/color; automatic, inline, vertical or icon labels. Inside padding and gaps between grouped modules have separate controls. Aerie controls only its own grouped gaps; macOS places separate items.
- **Network:** choose All, Selected or None from a readable interface list. Saved missing interfaces remain selectable. Every interface continues to be sampled; this choice changes aggregate bandwidth, history and speed notifications. Optional external-address lookup has its own consent.
- **Weather:** manually enter a point, explicitly find a city/ZIP through Apple geocoding, or request one Mac location through macOS. Ambiguous results require a selection. A chosen point can also fill daylight. Forecasts, maps and daylight remain under their own switches. Unconfigured weather stays hidden; a configured item remains stable when data is unavailable.
- **Date & Time:** follow Mac date/time format and zone by default, or type a custom format and see its example update. Existing custom formats are preserved. Configure world clocks, calendar/event display and offline daylight here.
- **Sensors:** read hardware-scoped names and the original code, edit a local alias directly, or manage saved aliases. Clear an alias to restore the supplied name. Community names do not prove physical core or component identity; unknown sensors keep a generic kind and original code.
- **Notifications:** choose a value, condition, readable limit/unit and waiting time. Sensor choices use names. Advanced controls expose ranges, recovery and repeat behavior. Add/update the draft, then Apply. State-change controls and their individual wait times live here too.
- **Shortcuts:** configure optional native global combinations, with conflicts reported after Apply.
- **Permissions:** explicit notifications, calendar, Wi-Fi identity and launch-at-login actions. These choices are independent of forecast/map consent.

Network menu numbers use reserved right-aligned columns, with download and upload stacked in every supported layout, including Combined dashboard. Graphs reuse existing history. Native gauges distinguish a valid zero from unavailable data. Provider-reported weather codes or recognized NWS icon metadata choose condition icons; a missing day/night flag never implies daytime. Grouped modules retain individual mouse, keyboard and accessibility actions.

This presentation is a development preview. Synthetic controls and drawing tests do not establish real rendering or the memory target; see [release acceptance](ACCEPTANCE.md).

A synthetic eight-module fixture uses 359 points in Compact layout, compared with 551 points for the same values in Text layout with four-point padding and six-point gaps. Its explicit 360-point budget models a 1440-point bar with a 200-point central reservation, 140 points for system controls and 120 for other items on one side. This is a reproducible layout budget, not a guarantee for every screen or foreground application. Additional weather and date/time items add their own measured widths; the preset does not silently hide modules. Separate-item system gaps remain under macOS control.
